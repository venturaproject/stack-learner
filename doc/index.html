A clear path for every learner

From courses
to assessment.

Learner brings course content, cohorts, student progress, and activity reviews together in one platform.

01 / ORGANIZE

Organizations and roles

Separate academies and teams with their own memberships and administrator, instructor, and student roles.

02 / DESIGN

Courses and content

Build courses from ordered modules and lessons, then publish the learning path when it is ready.

03 / GUIDE

Cohorts and enrollment

Organize course groups, assign instructors, and retain enrollment history, including withdrawals.

04 / PROGRESS

Sequential learning

Students complete lessons in order and see their progress without accessing locked content.

05 / SUBMIT

Task activities

Accept text or link submissions and keep every attempt in the student's submission history.

06 / REVIEW

Grading and feedback

Organization admins and assigned instructors review attempts, award a score from 0 to 100, and leave feedback.

Small surface, clear boundaries

Built to evolve.

A web application and API organized as a modular monolith, with permissions and organization boundaries enforced by the backend.

Go API

Gin exposes organization, course, cohort, progress, and assessment operations. Use cases and domain rules are separated from HTTP and persistence adapters.

React application

React and TypeScript power web workflows for managing courses, enrollments, and cohorts, as well as completing and reviewing activities.

Data and services

PostgreSQL stores application data and versioned SQL migrations manage the schema. Redis is part of the runtime services.

Deploy your way

Docker Compose runs the API, frontend, PostgreSQL, Redis, and Nginx for development or self-hosted deployment.

Start with Learner.

Run the development stack with Docker and create an organization to start building courses and cohorts.
